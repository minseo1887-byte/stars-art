# 별을 잇다 · v2.2

천상열차분야지도 종이본의 성도를 확대하고 이동하며, 북두칠성과 심수의 별과 연결선을 빛으로 감상하는 웹 작품입니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. JSON을 HTTP로 읽기 때문에 파일을 더블클릭해 여는 방식은 지원하지 않습니다. 빌드나 브라우저 런타임 의존성은 없습니다.

## Netlify 배포

Netlify에 연결된 GitHub `main`에 푸시하면 자동 배포됩니다. 배포 폴더는 저장소 루트입니다. 포함된 `netlify.toml`이 이를 지정하며 빌드 명령은 비워 둡니다.

## 파일 구조

| 경로 | 역할 |
| --- | --- |
| `index.html`, `src/style.css` | 감상 화면과 조작 메뉴, 반응형 스타일 |
| `src/app.js` | 성관 검색, 화면 선택, 강조 레이어 및 정보 패널 |
| `src/camera.js` | 성도 좌표와 화면 좌표 변환, 확대·이동 및 성관 초점 애니메이션 |
| `src/modes.js` | 상단 탐색·감상 모드 전환 |
| `src/gestures.js` | 드래그, 핀치, 클릭, 휠 입력 |
| `data/constellations.json` | 이미지 크기, 좌표, 연결선, 출처 ID, 검증 대기 후보 |
| `assets/chart.webp` | 국립중앙박물관 이미지의 원형 성도 가공본 |
| `assets/prepare-chart.py` | 이미지 가공 재현 도구 |
| `CREDITS.md` | 원본 링크, 이용 조건, 좌표 확인 범위 |

## 성도 및 성관 수정

좌표 원점은 이미지 왼쪽 위입니다. `stars`는 배포 이미지의 픽셀 좌표이며, `edges`의 숫자는 `stars`의 0부터 시작하는 배열 인덱스입니다. 원본 사진에서 측정한 값은 크롭의 왼쪽 위 `(260, 680)`을 빼서 변환합니다. SVG의 한 그룹 안에서 이미지와 강조 레이어가 같은 변환을 사용하고, 터치 판정도 동일한 카메라를 사용합니다.

가공 이미지는 CREDITS의 사진을 받아 `python3 assets/prepare-chart.py source.jpg assets/chart.webp`로 재현할 수 있습니다. 이 명령에만 Pillow와 NumPy가 필요합니다. 다른 판본으로 교체할 때는 이미지뿐 아니라 크기, 출처, 각 별의 좌표와 연결선을 함께 갱신합니다.

심수는 ‘心三’ 표기, 별 3개, 연결선 2개를 사진과 대조해 추가했습니다. 직녀·견우·삼태성·묘수는 검증 대기 항목입니다. 항목별 검토 내용과 해설 출처는 CREDITS를 참고하세요.

## 학생 창작 모드 확장

읽기 전용 탐색 데이터는 그대로 참조하고, 창작 모드의 문서는 별도 모듈과 저장소에서 관리합니다. 창작 문서에 기준 이미지의 `sourceId`, 학생이 고른 점과 선, 빛·색·모션·오디오 설정을 기록하는 방식을 권장합니다. 카메라의 좌표 변환과 입력 모듈을 재사용하면 성도 위에 독립 SVG 그룹을 얹어 창작 레이어를 편집할 수 있습니다.

## v2 탐색

- 교실 화면 왼쪽의 성관 목록에서 한글 또는 한자로 검색할 수 있습니다. 모바일에서는 ‘성관 탐색’을 눌러 목록을 펼칩니다.
- 목록에서 성관을 고르거나 지도에서 별을 누르면 해당 위치로 이동하며 별과 연결선이 차례로 나타납니다. 선택한 성관의 이름을 눌러 정보 패널을 접거나 펼칠 수 있습니다.
- 상단의 감상 모드는 탐색 UI를 숨깁니다. 창작 모드는 향후 구현 과제입니다.
- 확대 비율은 전체 맞춤 보기 기준이며, 뷰포트가 바뀌어도 조정된 배율과 성도상의 중심점을 유지합니다. 시스템에서 동작 줄이기를 설정한 경우 성관으로 즉시 이동합니다.

## 검증 범위

- Chromium에서 1280×720 교실 화면과 390×844·844×390 모바일 뷰포트를 테스트했습니다. 한글·한자 필터, 선택 표시, 성관 초점 이동, 지도 좌표 선택, 드래그·휠·두 손가락 핀치·초기화, 방향 전환 시 확대율·중심·선택 유지, 패널 접기, 모드 전환 및 동작 줄이기를 확인했습니다.
- 모바일 입력은 Chromium에서 모의 터치로 검사했습니다. 실제 휴대폰의 입력 감각, Safari 호환성, 저사양 기기의 애니메이션 성능은 확인이 필요합니다.

## v2.2 애니메이션

- 다른 성관으로 전환하면 천문도 전체를 먼저 보여 주고, 넓은 시야에서 대상 쪽으로 이동한 뒤 확대합니다. 이동 구간의 길이는 성도 중심에서 대상까지의 거리에 따라 조정합니다.
- 초점 이동 뒤 별이 210ms 간격으로 점등되며, 각 별의 밝기와 원형 그라데이션 휘광이 1.15초에 걸쳐 차오릅니다. 연결선은 선명한 중심선과 옅은 바깥광을 겹쳐 그립니다.
- 이동 중 다른 성관을 고르면 현재 화면 위치에서 새 경로를 시작합니다. Chromium에서 두 성관 사이의 양방향 이동, 재선택, 점등 중간값, 연결선의 그리기 진행과 완료 화면을 확인했습니다.
