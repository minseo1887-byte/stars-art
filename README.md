# 별을 잇다 · v1

천상열차분야지도 종이본의 성도를 확대하고 이동하며, 북두칠성의 일곱 별과 연결선을 빛으로 감상하는 웹 작품입니다.

## 실행

압축을 푼 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. JSON을 HTTP로 읽기 때문에 파일을 더블클릭해 여는 방식은 지원하지 않습니다. 빌드나 브라우저 런타임 의존성은 없습니다.

## Netlify 배포

수동 배포는 ZIP을 푼 뒤 `index.html`이 바로 들어 있는 폴더를 Netlify Drop에 올립니다. Git 연동 시 배포 폴더는 저장소 루트입니다. 포함된 `netlify.toml`이 이를 지정하며 빌드 명령은 비워 둡니다.

## 파일 구조

| 경로 | 역할 |
| --- | --- |
| `index.html`, `src/style.css` | 감상 화면과 조작 메뉴, 반응형 스타일 |
| `src/app.js` | 성관 검색, 화면 선택, 강조 레이어 및 정보 패널 |
| `src/camera.js` | 성도 좌표와 화면 좌표 변환, 확대·이동 상태 |
| `src/gestures.js` | 드래그, 핀치, 클릭, 휠 입력 |
| `data/constellations.json` | 이미지 크기, 좌표, 연결선, 출처 ID, 검증 대기 후보 |
| `assets/chart.webp` | 국립중앙박물관 이미지의 원형 성도 가공본 |
| `assets/prepare-chart.py` | 이미지 가공 재현 도구 |
| `CREDITS.md` | 원본 링크, 이용 조건, 좌표 확인 범위 |

## 성도 및 성관 수정

좌표 원점은 이미지 왼쪽 위입니다. `stars`는 배포 이미지의 픽셀 좌표이며, `edges`의 숫자는 `stars`의 0부터 시작하는 배열 인덱스입니다. 원본 사진에서 측정한 값은 크롭의 왼쪽 위 `(260, 680)`을 빼서 변환합니다. SVG의 한 그룹 안에서 이미지와 강조 레이어가 같은 변환을 사용하고, 터치 판정도 동일한 카메라를 사용합니다.

가공 이미지는 CREDITS의 사진을 받아 `python3 assets/prepare-chart.py source.jpg assets/chart.webp`로 재현할 수 있습니다. 이 명령에만 Pillow와 NumPy가 필요합니다. 다른 판본으로 교체할 때는 이미지뿐 아니라 크기, 출처, 각 별의 좌표와 연결선을 함께 갱신합니다.

직녀·견우·삼태성·묘수·심수는 판본의 표기와 연결선 검증 대기 항목입니다.

## 학생 창작 모드 확장

읽기 전용 탐색 데이터는 그대로 참조하고, 창작 모드의 문서는 별도 모듈과 저장소에서 관리합니다. 창작 문서에 기준 이미지의 `sourceId`, 학생이 고른 점과 선, 빛·색·모션·오디오 설정을 기록하는 방식을 권장합니다. 카메라의 좌표 변환과 입력 모듈을 재사용하면 성도 위에 독립 SVG 그룹을 얹어 창작 레이어를 편집할 수 있습니다.

## 검증 범위

북두칠성의 표시 좌표 일곱 개와 원본 사진의 표식 중심을 확대 대조했습니다. 소장품 상세 페이지와 공공누리 제1유형 표시를 확인했습니다. 실제 스마트폰의 터치 감각과 저사양 기기의 프레임 성능은 별도 확인이 필요합니다.

Node에서 탭·드래그·핀치·휠·초기화를 모의 입력으로 검사했습니다. 이미지와 터치 판정의 좌표 일치 및 가로·세로 크기 전환 후 확대율과 중심점 유지도 확인했습니다. 브라우저 미리보기 연결 시간 초과로 데스크톱과 모바일 레이아웃을 실제 브라우저에서 확인하는 절차는 남아 있습니다.
